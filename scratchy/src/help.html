scratchy

A quick reference for everything the command bar and keybindings do today. This page is rendered by scratchy's own layout engine, the same as any other page — and gets updated here as features are added.

Normal mode

KeyEffect
jScroll down
kScroll up
Ctrl+dScroll down half a page
Ctrl+uScroll up half a page
:Enter the command bar

Command bar

Press :, type a command, then Enter to run it. Tab completes the current word (a command name, or set's own vim/novim argument) — press Tab again right after to cycle through any other matches. Ctrl+v pastes from the clipboard — useful for a URL copied from somewhere else. Escape cancels without running anything.

CommandEffect
:go <url>Navigate to a URL
:set vimTurn vim-mode key handling on
:set novimTurn vim-mode key handling off (every key then passes straight through to the page)
:helpShow this page
:q or :quitClose scratchy
