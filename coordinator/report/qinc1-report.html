Recommendation: ready to make the engine the default (QINC1l), when you say so.

What I looked at by eye

  • social.loupax.com: the only steady pixel difference (0.22%) is the line-number gutter next to the article image. With the flag on, the image takes one gutter line, which matches Chrome. With the flag off, the gutter numbers the image's 21 px placeholder height row by row. This is the known QINC1k5 finding; flag-on is the correct one.
  • YouTube: pixel differences of 4–58% appear just as often between two flag-off runs. They come from the recommendations, thumbnails and video frame changing between runs.
  • YouTube player error: one flag-on watch run ended on YouTube's "an error occurred" screen. Its log shows DNS lookups failing for the video host (*.googlevideo.com). Two flag-off runs had the same DNS failures in the same series, so this is the network, not the engine.
  • Wikipedia, github, BBC, hover page: layout, text and images are identical in both modes.
  • Memory: peak memory is within about 10% between modes on most pages. Headless Wikipedia uses 25% more (276 vs 220 MB). github sits near 1.7 GB in both modes. Every run stayed under the 6 GB cap.
