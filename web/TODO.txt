Architecture C (user, 2026-11-23; DECISIONS.md "Architecture C"): web-shell is a small
Wayland compositor (smithay) that draws the shell (status bar, command line, later tabs
and hints) and owns all input; the page is drawn by an engine host, a separate program
with no browser UI of its own (Blink through CEF, web-host-cef; a lighter engine later) that the shell
drives over a control socket in our own protocol. Network: standard connectivity by
default; the optional `--proxy <host:port>` (any HTTP forward proxy, plain requests and
CONNECT) is handed to the engine host. A missing `--proxy` is never an error. web does not enforce that nothing bypasses the proxy:
running it in an empty network namespace is a separate, engine-neutral wrapper, not
part of web (DECISIONS.md "No enforcement in web").
No browser extension, no automation protocol (CDP, BiDi).

Order (user, 2026-11-23): Blink first, to have something working as soon as possible;
a lighter engine (web-host-webkit, E1) only after C8. C1 can run before any compositor
code (inside the nested dwl from ../scratchy/tools/nest.sh). Each step ends with a check, so the plan can
stop early on a hard failure.
