Architecture C (user, 2026-11-23; DECISIONS.md "Architecture C"): web-shell is a small
Wayland compositor (smithay) that draws the shell (status bar, command line, later tabs
and hints) and owns all input; the page is drawn by an engine host, a separate program
with no browser UI of its own (web-host-cef first, web-host-webkit second) that the shell
drives over a control socket in our own protocol. The engine host runs in an empty
network namespace and reaches the network only through a web proxy: any HTTP forward
proxy (plain requests and CONNECT) on a Unix socket, given with `--proxy <socket path>`.
No browser extension, no automation protocol (CDP, BiDi).

Order: C1 and C1b can run before any compositor code (inside the
nested dwl from ../scratchy/tools/nest.sh). Each step ends with a check, so the plan can
stop early on a hard failure.
